# merry-maple-mini



留着备查的示例

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/merry-maple-mini.git
cd merry-maple-mini
cargo build --release
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
